# Data & interface contract

Everything here is **synthetic**. Synthea supplies demographics, diagnosis dates, anthropometrics, lipids and smoking history.
Longitudinal labs, fasting insulin, complications, medications, genotypes and all device streams are generated by this repo.
Genotypes, the polygenic score and device streams are **SIMULATED**.

## Architecture

```
Synthea (Apache-2.0) ──► EHR tables ─────────────────────────────┐
  data/synthea_raw       ehr/build_ehr.py                         │
                           │ features.ehr_features                │
                           ▼                                      ▼
                    wearables/derive_params.py          ingestion.fuse_with_ehr
                           │ (EHR → physiology)                   ▲
                           ▼                                      │
                    wearables/simulate.py                         │
                    (simglucose ODE + behaviour)                  │
                           │                                      │
                           ▼                                      │
   Raw Device Streams ──► Ingestion & Alignment ──► Fused Patient Timeline ──► models/ablation.py ──► dashboard/app.py
   raw_wearables/*.parquet  ingestion/align.py       fused_timeline.parquet
   (native rates, long)     align_to_timeline        (timeseries.parquet = aligned, pre-fusion)
```

`timeseries.parquet` is **derived**: it is only ever written by `ingestion/align.py`, never by the simulator.

## EHR tables

* `patients.csv` — `patient_id, age, sex, race, birth_date, height_cm, weight_kg, bmi` (bmi = kg/m², consistent), `hba1c, fasting_glucose, fasting_insulin, homa_ir, total_chol, ldl, hdl, triglycerides, creatinine, egfr, alt` (all equal the latest visit in `labs.csv`), `diabetes_status` (t2d/prediabetes/none), `diabetes_onset_date, years_since_dx, smoking_status` (never/former/current), `family_history_diabetes, family_history_cvd` (0/1), `genetic_risk_score` (0–1, SIMULATED), `genetic_risk_flag` (top cohort quartile), `genetics_label`.
* `conditions.csv` — `patient_id, condition, onset_date, status(active/resolved)`. Conditions: Type 2 diabetes, Prediabetes, Hypertension, Dyslipidemia, Obesity (BMI≥30), Chronic kidney disease (stage 1–3), Diabetic retinopathy, Diabetic neuropathy, Coronary artery disease. Complication / CKD probability rises with diabetes duration and HbA1c (logistic); eGFR is drawn per CKD stage.
* `labs.csv` — `patient_id, date, test, value, unit`; 4–8 visits in the 730 days before `ANCHOR` (2026-09-30). Tests: HbA1c, fasting glucose, fasting insulin, total cholesterol, LDL, HDL, triglycerides, serum creatinine, eGFR (CKD-EPI 2021 ↔ creatinine), ALT. Values random-walk backwards from the latest visit (HbA1c can trend either way; LDL higher before statin start; eGFR declines). HOMA-IR = glucose[mg/dL] × insulin[µIU/mL] / 405, derived.
* `medications.csv` — `patient_id, medication, class, start_date, dose, status`. Classes: metformin, insulin (basal / bolus), SGLT2 inhibitor, DPP-4 inhibitor, sulfonylurea, statin, ACE inhibitor / ARB. Rules: insulin only in T2D; statin ← dyslipidemia / CAD / T2D age≥40; ACE/ARB ← hypertension / CKD / CAD; metformin withheld at eGFR<30.
* `genomics.csv` — `patient_id, snp_id, gene, genotype, risk_allele_count(0/1/2), label=SIMULATED`. SNPs: rs7903146 TCF7L2, rs5219 KCNJ11, rs1801282 PPARG, rs9939609 FTO, rs13266634 SLC30A8 (real variants; approximate European risk-allele frequencies and per-allele ORs in `config.SNPS`). Genotypes are drawn with frequency enriched in T2D (full OR) and prediabetes (half log-effect). Score = Σ ln(OR)·count / Σ 2·ln(OR).

## Raw device streams

Columns: `patient_id, source_device, metric, start_time, end_time, value, unit` (naive timestamps, one parquet per patient).

| source_device | metric (unit) | native rate |
|---|---|---|
| Dexcom G7 (simulated) | `glucose` (mg/dL) | every 5 min; AR(1) sensor noise; 30-min warm-up gap at start (and at day-10 sensor change); random 15–120 min dropouts |
| Apple Watch (simulated) | `heart_rate` (count/min) | 1 min within 10 min of activity, otherwise irregular 5–10 min |
| | `hrv_rmssd` (ms) | 3–5 daytime spot readings + 4–8 overnight |
| | `steps` (count) | irregular segments (≤26 min) summing per-minute counts |
| | `sleep_stage` (stage_code) | segments: 0 InBed, 1 Awake, 2 Core/Light, 3 Deep, 4 REM |
| | `resting_heart_rate` (count/min) | 1/day |
| | `spo2` (%) | every 10–15 min overnight |
| | `wrist_temp_deviation` (degC) | 1/night |
| | `active_energy` (kcal) | per active minute; ∝ steps and HR above resting |
| Manual log / Insulin pen (simulated) | `carbs_logged` (g), `insulin_bolus` (U), `insulin_basal` (U) | events. **Under-logged**: each meal is logged with per-patient probability 0.35–0.95 (lower at BMI≥30) with ~25 % carb mis-estimation; bolus log probability 0.5–0.97. Ground truth is not exposed. |

The wearable window is the `days` days (7 sample / 14 full) starting 2026-10-01, i.e. the day *after* the latest possible lab date.

## EHR → physiology (`wearables/derive_params.py`)

| EHR input | Simulator effect |
|---|---|
| HOMA-IR (primary), HbA1c, smoking, polygenic score, age | insulin sensitivity ↓ (scales `Vmx`, `kp3`) |
| BMI | glucose clearance ↓ (`k1`) |
| eGFR | insulin clearance ↓ (`m4`) → prolonged insulin action |
| HbA1c, years since dx, polygenic score, DPP-4 | beta-cell response (PI gain, secretion ceiling, meal-time release) |
| SGLT2 inhibitor | renal excretion threshold ↓ / slope ↑ → lower peaks |
| Sulfonylurea | secretion floor not suppressed at low glucose → hypo risk |
| Metformin | hepatic glucose output −8 % (`kp1`) |
| Insulin therapy | exogenous basal + meal bolus via sc depot |
| HbA1c | one-parameter calibration of the secretion set-point so that mean glucose ≈ eAG = 28.7·HbA1c − 46.7 |

Behaviour: daily steps fall with BMI, age and comorbidity count. Next-day insulin sensitivity is multiplied by up to ~0.8–0.9 after short/inefficient sleep or a low-activity day; activity raises sensitivity for ~90 min.

## Ingestion & alignment (`ingestion/align.py`)

* `load_raw_streams(patient_id, profile)` → raw long DataFrame.
* `align_to_timeline(raw, freq="5min")` → one row per 5 min: `glucose` (nearest reading within ±2.5 min; linear interpolation only across gaps ≤15 min), `glucose_imputed`, `device_gap_minutes` (minutes since last real CGM reading), `hr` (mean, ffill ≤10 min), `hr_missing` (no raw reading in bin), `steps`, `active_energy` (sums; step segments spread uniformly over their minutes), `sleep_stage` (segment covering the bin; −1 = none), `carbs_logged`, `insulin_bolus_logged`, `insulin_basal_logged`, and forward-filled daily metrics `resting_hr, rhr_trend_7d, hrv_rmssd_latest, wrist_temp_dev, sleep_hours_last_night, sleep_efficiency_last_night, spo2_night_min` (each only from the moment it is known, e.g. last night's values from wake time).
* `fuse_with_ehr(timeline, ehr_tables)` → timeline + EHR features. **Leakage rule:** per day, only labs dated strictly before that day, conditions with onset before that day, medications started before that day. Covered by `tests/test_pipeline.py::test_fuse_no_future_lab_leakage`.

## Model features (`features.py`)

* Wearable: current/lagged glucose (15/30/60 min), rate of change, 60-min mean/std, HR, steps (30/60 min), active energy (last 60 min), time of day, asleep flag, logged carbs/bolus (3 h), minutes since logged meal, last-night sleep hours/efficiency, **resting-HR 7-day trend, nightly SpO2 minimum, wrist-temperature deviation**, quality flags.
* Snapshot EHR: age, sex, BMI, latest HbA1c, fasting glucose, LDL, HDL, triglycerides, total cholesterol, eGFR, creatinine, ALT.
* Full EHR adds: **2-year slope** of HbA1c / fasting glucose / LDL / eGFR, HOMA-IR, comorbidity count, diabetes-complication flag (retinopathy, neuropathy, CKD), count of glucose-lowering drug classes (+ metformin/SGLT2/SU/DPP-4/insulin/statin/ACE-ARB flags), per-SNP risk-allele counts + polygenic score, smoking, family history, years since diagnosis.
* Task: predict glucose 60 min ahead (LightGBM on Δ = g(t+60) − g(t), L1 loss), patient-grouped 5-fold CV. Models: Persistence · Wearable-only · **Fused (snapshot EHR only)** · Fully fused.

## Known limitations

* The glucose model is the T1D UVA/Padova ODE used as a generic glucose–insulin system, with a PI controller standing in for beta-cell secretion; it is a plausible simulator, not a validated T2D model.
* Because the EHR is the simulator's input, any EHR-model gain is built in; the experiment shows the pipeline can recover it, not that it exists in real patients.
* Synthea has few current smokers and no fasting insulin, genotypes or reliable HbA1c for non-diabetics: these are generated/resampled here (14 % current smokers; HbA1c re-grounded by status).
